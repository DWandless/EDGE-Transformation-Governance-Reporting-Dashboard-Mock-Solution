# EDGE Transformation Governance & Reporting Dashboard

A React-based dashboard for monitoring and filtering governance issues across transformation projects.

## Prerequisites

- Node.js (v14 or higher)
- npm (comes with Node.js)

## Installation

1. Navigate to the project directory:
```bash
cd governance-dashboard-mock
```

2. Install dependencies:
```bash
npm install
```

## Running the Application

Start the development server:
```bash
npm start
```

The app will automatically open in your browser at [http://localhost:3000](http://localhost:3000)

## Available Scripts

- **`npm start`** - Runs the app in development mode
- **`npm test`** - Launches the test runner
- **`npm run build`** - Builds the app for production to the `build` folder
- **`npm run eject`** - Ejects from Create React App (one-way operation)

## Features

- View governance and reporting data in a filterable table
- Filter by 12 governance attributes to identify data quality issues
- Responsive dashboard interface
